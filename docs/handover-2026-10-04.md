## Starten

Voor de Quest (HTTPS, zelfgetekend certificaat accepteren):

```bash
cd ~/IOL_Cessna_Demo
npm run dev:all
```

Dan op de Quest `https://<ip van deze computer>:5173/` openen. Het adres van deze computer was `192.168.1.237`. Voor testen in de browser-pane van Claude is HTTP nodig: `npm run dev:codex:all`.

Na een herstart van de server zijn oude sessiecodes ongeldig; maak een nieuwe docentsessie.
